# 100 random projects

Each project lives in its own numbered folder and is built end to end by `/sidstack:ship` (https://github.com/csarigumba/sidstack): planned, built by parallel agents, proved on the real app, reviewed by a fresh-context agent, and opened as a PR with evidence. I merge.

From project 2 on, `/sidstack:factory` runs the board, this repo's GitHub Project (Backlog, Ready, Building, QA, Review, Blocked, Done). Each project is an issue in Ready, worked by a fresh headless `/sidstack:ship #<n>` whose lanes move the card, and merged by a script only when the reviewer said `ship` on the exact head commit, no path matches `.factory/escalate`, and `.factory/check` (every folder's `npm test`) passes on that commit. Anything else lands in Blocked with the reason on the issue. The table below is regenerated by `.factory/readme` after each run.
